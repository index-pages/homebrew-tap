# Homebrew tap of Index Pages

```sh
brew install index-pages/tap/getdr
```

| Formula | What it is |
|---|---|
| `getdr` | Command-line tool to check Ahrefs Domain Rating (DR) of domains – [index-pages.com/getdr/](https://index-pages.com/getdr/), [source](https://github.com/index-pages/getdr) |

The formulae install the prebuilt binaries from each project's GitHub Releases, checked by sha256. They are
written by the projects' release workflows, so changes belong in the project repos, not here.
